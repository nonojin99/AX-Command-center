# 3. BigDataQuery 쿼리 자리 (데이터 승인 후 채움)

- 테이블·컬럼명은 사내 스키마 확인 후에만 쓴다. 추측하지 않는다.
- 쿼리 파일 한 개 = 판단 기준표의 "확인할 데이터" 한 항목. 파일명: `<DEFECT_CODE>_<항목>.sql`
- 파일 맨 위 주석에 목적·입력 파라미터·기대 출력 컬럼을 적는다.

```sql
-- 목적: <무엇을 확인하는 쿼리인가>
-- 파라미터: @lot_id, @from_ts, @to_ts
-- 출력: <컬럼 목록>
SELECT
  /* TODO: 스키마 확인 후 작성 */
FROM `<PROJECT.DATASET.TABLE>`
WHERE lot_id = @lot_id
```

- 쿼리 결과(실데이터)는 저장소에 커밋하지 않는다.
