# 2. 판단 기준표 (엔지니어가 채우는 핵심 문서)

Claude 가 "어떤 재료를 미리 모을지" 정하는 근거. 비어 있으면 AI 는 재료를 정할 수 없다.
**불량 유형 하나당 한 블록**을 복사해서 채운다.

## 불량 유형: `<DEFECT_CODE>` (이름)

| 질문 | 내용 |
|---|---|
| 이 불량이 의심될 때 **반드시 확인할 데이터** | (예: 해당 Lot 공정 이력, 직전/직후 Lot, 동일 장비 타 Lot) |
| 비교 기준 | (예: 최근 N주 평균, 관리 한계, 동일 장비군) |
| 원인 후보와 **그렇다고 볼 신호** | 후보1: 신호 / 후보2: 신호 |
| **그럴 가능성을 낮추는 신호** | |
| 에스컬레이션 기준 | (예: 동일 장비 2 Lot 이상, 수량 N 초과, 고객 출하 영향) |
| 보류·추가 확인이 필요한 경우 | |
| 과거 유사 사례 위치 | (보고서 링크 / 사례 번호) |

## 공통 규칙
- 긴급도 구분: 상 / 중 / 하 — 기준: (채울 것)
- 판단은 AI 초안 → 엔지니어 확정. 오판 사례는 `defect/misjudgments.md` 에 한 줄 기록하고 위 기준을 고친다.
