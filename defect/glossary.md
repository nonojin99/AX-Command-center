# 용어·불량코드 사전 (포털 Confluence 에 같은 표로 게시)

현장에서 쓰는 말과 데이터 이름을 연결한다. AI 오답 대부분이 이 연결이 없어서 생긴다.
**한 줄 = 한 용어.** 담당자(오너)를 반드시 적는다.

## A. 불량 코드
| 코드 | 공식 이름 | 현장에서 부르는 말 | 설명(한두 줄) | 관련 공정 | 판단 기준표 링크 | 오너 |
|---|---|---|---|---|---|---|
| `<DEFECT_CODE>` | | | | | | |

## B. 지표·용어
| 용어 | 정의(계산식 포함) | 데이터 위치(테이블.컬럼) | 기간 기준 | 주의할 점 | 오너 |
|---|---|---|---|---|---|
| | | `<PROJECT.DATASET.TABLE.COLUMN>` | | | |

## C. 같은 말 다른 뜻 (충돌 기록)
| 용어 | 뜻 1 (팀/사람) | 뜻 2 | 합의된 정의 | 날짜 |
|---|---|---|---|---|
| | | | | |

> 규칙: 정의를 바꾸면 날짜와 이유를 남긴다. 테이블·컬럼명은 확인된 것만 쓴다.
