# 포털 홈 구성안 (Confluence 홈 + 필요 시 HTML 카드)

## 사용자 구분 (Claude Code 신청 여부에 따라)
- **만드는 사람 (≈30%)**: 스킬 실행, 요약 생성, 해석 초안 작성
- **보는 사람 (≈70%)**: 포털에서 결과 열람, 사전 검색, 요청·피드백

## 홈 카드 (최대 5개, 위에서부터)
| 순서 | 카드 | 누구에게 | 상태 | 내용 |
|---|---|---|---|---|
| 1 | 📊 오늘의 모니터링 요약 | 전원 | 샘플 | 최신 요약 html 임베드 + 이전 요약 목록 |
| 2 | 📖 용어·불량코드 사전 | 전원 | 작성 가능 | `defect/glossary.md` 내용 (검색 가능) |
| 3 | 📨 불량 메일 정리 / 분석 패키지 | 만드는 사람 | 준비 중(데이터 승인 후) | 사용법, 입력 예시, 결과 샘플 |
| 4 | 🙋 요청·오판 신고 | 전원 | 가능 | 폼 2종 (portal/request-form.md) |
| 5 | 🚀 시작하기 | 전원 | 가능 | portal/guide.md |

## 게시 방식
- **Confluence**: 사전, 가이드, 요청 폼 안내, 변경 이력 (사람이 편집하는 문서)
- **HTML**: `monitoring_report.py` 가 만든 요약 html (자동 생성, 날짜별 파일) — 사내 서버에 올리고 Confluence 에서 링크/임베드
- **Streamlit (2단계, 데이터 승인 후)**: 기간·지표 선택 등 인터랙티브 조회가 필요할 때만. 처음부터 만들지 않는다.
