# 요청·오판 신고 양식 (Confluence 템플릿 또는 폼)

## 1. 자동화 요청
- 제목:
- 지금 어떻게 하고 있나 (순서대로):
- 얼마나 자주, 한 번에 얼마나 걸리나:
- 입력은 무엇이고, 결과는 어떤 모양이면 좋은가:
- 쓰는 데이터/툴:
- 급한 정도: 상 / 중 / 하

## 2. 오판·오류 신고
- 어떤 결과물인가 (링크 또는 제목·날짜):
- 무엇이 틀렸나 (한 줄):
- 맞는 답 또는 근거 (알면):
- 반복되는 문제인가: 처음 / 가끔 / 자주

> 처리: 챔피언이 주 1회 분류 → 요청은 개발 백로그, 오판은 `defect/misjudgments.md` 와 판단 기준표에 반영
