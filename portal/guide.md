# 시작하기 (1페이지)

## 이 포털이 하는 일
부서에서 AI로 만든 분석·요약을 한곳에서 찾아 보고, 용어를 확인하고, 필요한 걸 요청하는 곳입니다.

## 나는 어디까지 쓸 수 있나
| | 할 수 있는 일 |
|---|---|
| 모두 | 요약·산출물 열람, 용어 사전 검색, 요청·오판 신고 |
| Claude Code 사용자 | 위 + 스킬로 분석 패키지·요약 초안 생성 |

> Claude Code 사용 신청은 `<신청 경로>`. 사용하지 않아도 포털의 결과는 모두 볼 수 있습니다.

## 결과를 읽는 법
- 각 결과에는 **상태**가 있습니다: `초안`(AI 작성, 미확인) / `검증됨`(엔지니어 확인) / `폐기`.
- **초안은 참고용**입니다. 의사결정에는 `검증됨`을 쓰세요.
- 판단에는 근거와 확신도(높음/중간/낮음)가 적혀 있습니다. 근거가 없으면 "근거 부족"으로 표시됩니다.

## 결과가 이상하면
요청·오판 신고 폼에 **무엇이, 어떻게 틀렸는지 한 줄**만 적어 주세요. 기준표 개선에 쓰입니다.
