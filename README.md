# AX 커맨드센터 (초안)

부서원이 각자 AI로 만든 산출물·템플릿·스킬을 **한 저장소에서 찾고, 재사용하고, 관리**하기 위한 저장소.
사내 GitHub 서버에 올려 사용한다. (데이터 사용 승인 전 단계: 실제 데이터 없이 구조·템플릿만 운영)

## 구조
| 폴더 | 용도 |
|---|---|
| `outputs/<이름>/` | 각자 만든 산출물. **맨 위에 머리말(templates/artifact-header.md) 필수** |
| `registry/INDEX.md` | 산출물 목록. `python3 tools/build_index.py` 로 자동 생성 (직접 수정 금지) |
| `templates/` | 머리말·공용 양식 |
| `defect/` | 불량 분석 업무 패키지 (메일 입력 스키마, 판단 기준표, 분석 패키지, 쿼리 자리) |
| `monitoring/` | 정기 모니터링 요약 (config·샘플 csv, 이상 판정은 `tools/monitoring_report.py`) |
| `hub/` | 분석 허브(Streamlit): 여러 DB 조인 분석·차트·보고서 (가상 데이터 골격, 실제 BDQ 연결 자리) |
| `portal/` | 사내 포털(Confluence/HTML) 게시용 홈 구성·가이드·요청 양식 |
| `.claude/skills/` | 팀 공용 Claude 스킬(명령어). 저장소를 받으면 모두 같이 쓴다 |

## 규칙 5개
1. 산출물은 `outputs/<본인>/날짜_제목.md` 로 두고 머리말을 채운다 (소유자·목적·사용 데이터·상태).
2. 올리기 전 `python3 tools/build_index.py` 를 실행해 INDEX 를 갱신한다. 머리말이 없으면 경고가 나온다.
3. **실제 데이터·고객/협력사 정보·개인정보는 커밋하지 않는다.** 샘플은 가상·익명화만 (`defect/sample/`).
4. AI 가 만든 판단은 `상태: 초안`으로 시작하고, 사람이 확인하면 `검증됨` 으로 바꾼다.
5. 공용 스킬·템플릿 변경은 Pull Request 로, 담당자 1명 이상 리뷰.

## 단계
- **0단계(지금)**: 저장소 + 머리말 + INDEX
- **1단계(데이터 승인 후)**: `defect/queries/` 에 BigDataQuery 쿼리 연결, 판단 기준표 확정
- **2단계**: 스킬 사용 이력·정확도 기록 (오판 사례 → 기준표 개선)
