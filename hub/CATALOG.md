## 2. 조인 규칙
| 붙이는 것 | 키 | 관계 | 주의 |
|---|---|---|---|
| npw ↔ npw_defect | measure_id | 1:N | |
| npw ↔ edx | measure_id | 1:N | edx 는 결함 일부만 있음 → npw 기준 left join 하면 EDX 없는 측정이 생김(정상) |
| npw ↔ pm | eqp_id + 시각 | 시간 조인 | 'PM 후 경과일' = 측정 시각 이전 가장 가까운 PM 과의 차이 (`merge_asof`). 단순 eqp_id 조인 금지 → 행이 폭증한다 |
| npw ↔ parts | eqp_id + 시각 | 시간 조인 | 측정 시점에 장착 중인 파트 = `install_ts <= ts < remove_ts(없으면 현재)` |
